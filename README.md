## 📌 About the Project

CyberGuard AI is a Python-based cybersecurity expert system developed to support cybersecurity awareness and help users understand common digital security risks. The application provides an interactive web interface for exploring security concerns and receiving relevant recommendations based on the assessment logic implemented in the system.

The project aims to make cybersecurity information easier to understand and encourage users to follow safer digital practices.

## 🎯 Objectives

- Improve awareness of common cybersecurity threats.
- Help users understand potential security risks.
- Provide practical recommendations for safer online activities.
- Present cybersecurity guidance through an interactive web application.
- Demonstrate the use of Python and expert-system concepts in cybersecurity.

## ✨ Features

- **Interactive Web Interface:** A user-friendly application built with Streamlit.
- **Security Assessment:** Evaluates user-provided information according to the implemented application logic.
- **Security Guidance:** Presents relevant recommendations for cybersecurity awareness.
- **Threat Awareness:** Encourages users to recognise common online security concerns.
- **Professional Design:** A cybersecurity-themed interface with custom styling.
- **Educational Purpose:** Helps users learn about preventive security practices.

*Note: Actual assessment categories and features depend on the functionality implemented in the project code.*

## ⚙️ How It Works

1. **User Input:** The user opens the application and provides the requested security information.
2. **Assessment:** The application processes the supplied information.
3. **Evaluation:** The implemented assessment logic determines the relevant output.
4. **Results:** The application presents security information or recommendations.
5. **Prevention:** Users can apply appropriate safety measures based on the guidance provided.

## 🚀 Installation and Setup

### Step 1: Clone the Repository

Open a terminal and execute:

```bash
git clone https://github.com/GayathriBotta/Cyber-Security.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Cyber-Security
```

### Step 3: Install Dependencies

If a `requirements.txt` file exists, install the project dependencies using:

```bash
python -m pip install -r requirements.txt
```

If the project only requires Streamlit and it is not already installed, run:

```bash
python -m pip install streamlit
```

Install any other dependencies required by your actual application.

### Step 4: Run the Application

Run the following command from the directory containing `app.py`:

```bash
python -m streamlit run app.py
```

### Step 5: Open the Application

Streamlit will display a local URL in the terminal, usually:

```text
http://localhost:8501
```

Open the displayed URL in your browser to use the application.

## 🔐 Cybersecurity Best Practices

CyberGuard AI promotes awareness of practices such as:

- Using strong and unique passwords.
- Enabling multi-factor authentication.
- Avoiding suspicious links and email attachments.
- Keeping software and operating systems updated.
- Never sharing passwords or one-time passwords.
- Verifying unexpected requests for personal information.
- Using secure networks and trusted websites.
- Reporting suspicious activity through appropriate channels.
